# Netflix Data Analysis Using SQL Server

##  Project Overview
This project focuses on analysing the Netflix dataset using Microsoft SQL Server to explore content distribution, release trends, ratings, genres, and country-wise content availability. The objective is to extract meaningful insights using SQL queries.

##  Questions Solved 
- Analyse the distribution of Movies and TV Shows.
- Identify trends in content releases over the years.
- Explore country-wise content distribution.
- Analyse content ratings and genre.
- Identify top performing actor.
- Identify patterns in movie durations and TV show seasons.

##  Tools & Technologies
- **Database:** Microsoft SQL Server
- **Language:** SQL 
- **Dataset:** Netflix Movies and TV Shows Dataset

## SQL Concepts Used
- Aggregate Functions (COUNT, SUM, AVG)
- GROUP BY and ORDER BY
- WHERE and HAVING
- Subqueries
- Common Table Expressions (CTEs)
- Window Functions (DENSE_RANK, RANK)
- String Functions
- CASE Statements
- Data Cleaning and Handling NULL Values
- STRING_SPLIT function 

## Key Analysis & Insights

- **97.32%** of records are movies and just **2.68%** of records are TV shows.
- **USA** has the highest number of title count recording **1844** content over the platform.
- **2019** was the year with the highest number of contents added recording **1264** number of title count in the year.
- **TV-MA** is the most common rating for both type of content.
- **The school of mischief** is the longest movie with duration of 253 min..
- **Dramas, international movies** have highest number of content available on the platform followed by **Stand-up comedy**.
